# GEN505 - Grafos

Repositório destinado ao armazenamento das atividades, exercícios, códigos e trabalhos desenvolvidos na disciplina **GEN505 - GRAFOS**, realizada no semestre **2026.2**, durante o curso de **Ciência da Computação** da **Universidade Federal da Fronteira Sul - UFFS, Campus Chapecó**.

A disciplina será desenvolvida utilizando a linguagem de programação **C++**, com foco no estudo e implementação de algoritmos aplicados a teoria dos grafos.

---

## 📚 Sobre a Disciplina

Os conteúdos, algoritmos e exercícios práticos desenvolvidos durante as aulas serão adicionados a este repositório progressivamente, de modo que ele será atualizado ao longo de todo o semestre.

---

## 🛠️ Linguagem Utilizada

A linguagem utilizada para o desenvolvimento das atividades será:

```cpp
C++
```

---

## ▶️ Como Compilar e Executar

Para compilar os programas em C++, acesse a pasta do código desejado através do terminal e utilize o seguinte comando de compilação:

```bash
g++ -Wall -Wextra -pedantic *.cpp -o main
```

Em seguida, para rodar o código compilado, execute o seguinte comando:

```bash
./main
```

---

## 🎯 Objetivo do Repositório

Este repositório tem como objetivo organizar e documentar os códigos desenvolvidos durante a disciplina, servindo como material de estudo, consulta e acompanhamento da evolução dos conteúdos aprendidos.

Além disso, o repositório também funciona como registro prático da aplicação dos algoritmos de grafos utilizando C++.
